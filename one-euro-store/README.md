# €1 Store

A starter business website for a digital products brand selling low-cost downloads.

## Main categories
- Games
- Applications
- Ebooks
- AI Business Tools

## Files
- index.html: main landing page
- styles.css: store branding and layout
- script.js: small UI helper

## Next steps
1. Buy a domain such as 1eurostore.com
2. Connect a payment platform like Shopify, Lemon Squeezy, or Gumroad
3. Add your real digital products
4. Publish the site online with Netlify, Vercel, or Shopify
