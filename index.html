📋 How to Install

Android:
1. Tap Download APK on your Android phone.
2. Open the downloaded file.
3. If prompted, enable Settings → Install unknown apps.
4. Tap Install and you're ready!

iPhone:
1. Tap Open App — the app opens in Safari.
2. Tap the Share button (⬆️) at the bottom.
3. Select Add to Home Screen.
4. Now it's on your home screen like a real app!
